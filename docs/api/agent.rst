phenoforge.agent
=================

The LangGraph agent: decompose → check curated first → generate only for
unresolved terms → human confirmation gate on anything generated →
assemble. See :mod:`phenoforge.agent.graph`'s own docstring for the exact
interrupt/resume contract.
